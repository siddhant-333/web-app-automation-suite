Web App Automation Suite

Hi, I'm Siddhant. I'm learning software test automation and I created this project to get hands-on experience with API testing.

Right now, I'm working mainly with "Postman, JavaScript and Newman".

So far, I've been working on things like:

* Creating and testing API requests
* Testing different endpoints
* Checking status codes
* Checking JSON response data
* Writing JavaScript tests in Postman
* Testing both positive and negative scenarios
* Using Postman environments
* Running collections using Newman
* Generating test reports
* Using Git and GitHub to manage my work

I'm trying to make my tests check more than just whether an API returns "200". I also want to make sure the response contains the "correct information".
